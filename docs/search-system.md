# 検索システム（大規模アプリ対応）

巨大なアプリケーションでは、3 つの分析モードのように「対象を全件ロードして描画する」方式は破綻する
（ノード数が数万〜を超えるとレイアウトも描画も現実的でない）。本検索システムは、**全件をロードせず
境界付き（ページング・近傍）で探索する**ことでスケールさせる。

入口は 2 系統を用意する。

1. **絞り込み検索** … 検索窓（キーワード）＋種別（ラベル）ファセットで対象を絞り込む。
2. **Cypher 直接クエリ** … グラフDBへ Cypher を直接投入する（読み取り専用）。

> 一次定義は [`graph-model.md`](graph-model.md)。関連クエリは `src/server/neo4j/queries/search.ts`。

---

## スケーラビリティの考え方

- **常に境界付きで返す。** 検索結果は `LIMIT`（＋`SKIP`）でページングし、1 ページずつ取得する。
  次ページの有無は `LIMIT+1` 件取得して判定し、総件数の全走査（重い `count`）は避ける。
- **全文検索インデックスを使う。** `neo4j/schema/indexes.cypher` の `nodeSearch`
  （`name` / `label` / `path` / `id` を横断する FULLTEXT INDEX）でキーワード検索を高速化する。
- **ドリルダウンは近傍のみ。** 検索でヒットした 1 ノードを起点に、1 ホップの近傍だけを
  境界付き（`LIMIT`）で取得して描画する。そこからさらに隣接ノードへ辿って探索を広げる。
- **ファセット件数は概算。** 種別別ヒット数は集計前に上限（既定 2000）を掛けて過負荷を防ぐ。
  上限に達した場合は UI 上で「概算」と表示する。

---

## ① 絞り込み検索

- **キーワード**: `name` / `label` / `path` / `id` を全文検索する。
  - `nodeSearch` インデックスがあれば全文検索（前方一致トークン）を用いる。
  - 無い環境では `CONTAINS`（部分一致）にフォールバックする（UI に注記を表示）。
- **種別ファセット**: ヒットしたノードのラベル別件数を提示し、クリックで絞り込む（複数選択可）。
- **ページング**: 「前へ / 次へ」で `SKIP` を移動する。
- **ドリルダウン**:
  - 「近傍グラフを表示」… 選択ノードの 1 ホップ近傍を描画（`★` が中心。ノードクリックでさらに展開）。
  - IO 実行計画（`EXECUTES`→`IOOperation`）を持つ処理単位には「IO 実行計画へ ↗」を表示し
    IO 分析モード（`/io?unit=<id>`）へ横断する。

## ② Cypher 直接クエリ

- グラフDBへ任意の Cypher を投入し、結果を表形式で表示する（`Node` / `Relationship` は整形表示）。
- **安全策（多層防御）**:
  - **READ セッション**で実行（サーバー側でも書き込みは拒否される）。
  - 書き込み系キーワード（`CREATE` / `MERGE` / `DELETE` / `SET` / `REMOVE` / `DROP` /
    `FOREACH` / `DETACH` / `LOAD CSV`）を事前に弾く。
  - **トランザクションタイムアウト**（既定 5 秒）と**返却行数上限**（既定 1000 行）。

## API

| エンドポイント | メソッド | 用途 |
| :-- | :-- | :-- |
| `/api/search` | GET | 絞り込み検索。`q`, `kinds`(カンマ区切り), `offset`, `limit` |
| `/api/search/neighborhood` | GET | 指定ノードの 1 ホップ近傍。`id`, `limit` |
| `/api/search/cypher` | POST | 生 Cypher（読み取り専用）。ボディ `{ cypher, params? }` |

いずれも Neo4j 未接続時はサンプル（`neo4j/seed/sample.cypher` 相当）にフォールバックする
（生 Cypher を除く。生 Cypher は接続エラーをそのまま返す）。

---

## 補足

- 全文検索の解析器は標準（`standard`）のため、日本語は分割精度が限定的。日本語キーワードで
  取りこぼす場合は `CONTAINS` フォールバックや Cypher 直接クエリを併用する。
- `SKIP` / `LIMIT` に渡す数値は Neo4j の整数として渡す必要があるため、リポジトリ層で `neo4j.int()`
  に変換している（素の JS number は Float になり `LIMIT` で拒否される）。
